# ☕ Cafe Coffee Day – Online Ordering Web App

Welcome to **Cafe Coffee Day**, a full-stack web application that lets users browse a cafe menu and place customized orders online. 
Built with a Flask backend and a React frontend, the app demonstrates seamless client-server communication, validation, and user experience.

### 🌐 Live Site  
🔗 [Visit Now](https://arbaazkhanrs.github.io/Cafe-Coffee-Day/)

---

## 📦 Tech Stack

### Frontend:
- ⚛️ React
- 🎨 CSS
- 🖼️ Images & UI Assets
- 📦 Axios for HTTP requests

### Backend:
- 🐍 Python (Flask)
- 🔥 Flask-CORS
- 🖥️ Gunicorn (for deployment)
- 📦 Render (Python web service)

---

## ✨ Features

- 📋 Dynamic menu fetched from backend
- 📱 Mobile-responsive interface
- 📞 Phone number validation
- 🛒 Add items with quantity
- 💰 Live total calculation and order confirmation
- 🔗 Backend hosted on Render
- 🌍 Frontend hosted on GitHub Pages
